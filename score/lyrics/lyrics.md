## 第Ⅱ楽章「Kollision（衝突）」

### バスレチタティーフ（Bass Rezitativ）— mm.1-12

楽章冒頭、伴奏は Timp pp tremolo + Cb pizzicato のみ（最小伴奏）。

**ドイツ語原文：**

```
"O Grenze, nicht dieses Ende!
 Hier beginnt das wahre Lied!"
```

**日本語対訳：**

```
おお限界よ、これが終わりではない！
ここから真の歌が始まる！
```

**出典と変容：**

| | テキスト | 旋律音型 |
|-|---------|---------|
| ベートーヴェン第9番 | "O Freunde, nicht diese Töne!" | 宣言的下降音形（e'–d'–c'–B） |
| Symphony No. XI | "O Grenze, nicht dieses Ende!" | 宣言的上昇音形（B–c'–d'–e'–f'） |

→ 「否定」（O Freunde）から「肯定」（O Grenze）へ、旋律の方向を逆転。

**強弱指示：**
- f（"O Grenze"）→ ff（"beginnt"）→ ppp（"Lied"）

## 第Ⅴ楽章「Neue Grenze（新たな限界）」

### Tenor Solo — mm.340-380（第9番継承）

チェロが同じ音型をオクターブ下で同時演奏。

**ドイツ語原文：**

```
"Neu, wie eine Grenze weicht"
```

**日本語対訳：**

```
新しく、限界が退くように
```

**出典と変容：**

| | テキスト | 旋律音型 |
|-|---------|---------|
| ベートーヴェン第9番 | "Froh, wie seine Sonnen fliegen" | d'–f'–a'–d''（上昇アルペジオ） |
| Symphony No. XI | "Neu, wie eine Grenze weicht" | d'–f'–a'–b'（第9の4音保持、最終音を長7度へ） |

→ 「喜び（Freude）」が「新境地（Neue Grenze）」へ1音の差で変容。

---

### Strophe 1（第Ⅴ楽章 前半）— Soprano / Alto

合唱の本格的な登場部。Sが先行し、Aが5小節遅れでカノン。

**ドイツ語原文：**

```
Die Grenze ist nicht Ende,
sie ist der Ort, wo wir beginnen.
```

**日本語対訳：**

```
限界は終わりではない、
それは我々が始まる場所だ。
```

**声部指定：** S（先行）/ A（5小節遅れ、カノン）

---

### Strophe 2（第Ⅴ楽章 中間部）— Tenor / Bass

**ドイツ語原文：**

```
Im Schweigen hörten wir die Welt,
im Sturm erkannten wir uns selbst.
```

**日本語対訳：**

```
沈黙の中で我々は世界を聴いた、
嵐の中で我々は自己を知った。
```

**声部指定：** T + B（コラール様式）

---

### Coda（第Ⅴ楽章 最終部）— SATB Tutti + 全管弦楽

**mm.420-450 クライマックス。全合唱・全管弦楽 最大音量。**

**ドイツ語原文：**

```
Neue Grenze – neues Licht,
das Unmögliche – es zerbricht!
```

**日本語対訳：**

```
新たな限界 – 新たな光、
不可能なるもの – それは砕け散る！
```

**声部別最高音：**

| T | b' | ffff | テノール物理的上限域 |
| B | d（低音） | ffff | F1 最低音域からの到達 |

## オーケストラへの組込み（概要）

詳細は別途 `analysis/MC_オーケストラパート別技法要求書.md` Section 5 参照。

- **Ⅱ楽章 バスレチタティーフ**：Timp pp tremolo + Cb pizzicato の最小伴奏のみ
- **Ⅴ楽章 Tenor Solo**：Vc が同じ音型をオクターブ下で同時演奏
