# Symphony No. XI "Grenze"（限界）— MB. ベートーヴェン様式との比較分析

---

## 前提：Symphony No. X 第5楽章「全休符」の後に続く音楽

Symphony No. X の第5楽章が「全休符」（完全な沈黙）であったとするならば、No. XI "Grenze" はその沈黙の*意味の問い直し*から始まる。沈黙は終止ではなく、**閾（しきい）**である。

## 1. 第9番との比較 Markdownテーブル

| 比較軸 | 第9番 ニ短調 Op.125（1824） | Symphony No. XI "Grenze"（2026） |
|---|---|---|
| **形式** | 4楽章（ソナタ／変奏／スケルツォ／声楽付きフィナーレ） | 5楽章（ソナタ／トッカータ／間奏曲／パッサカリア／フーガ＋コーダ） |

## 2. ベートーヴェン様式の継承点（5点）と逸脱点（5点）

### ✅ 継承点

| # | 継承点 | 具体的手法 |
|---|---|---|
| 1 | **動機労作（Motivarbeit）** | 冒頭単音C♯を全5楽章に変形展開。第9番の「タタタター」と同様の細胞的構造 |
| 2 | **形式的緊張と解放** | ソナタ形式の提示部→展開部での調性不安定→再現部での解決という弁証法的進行 |
| 3 | **サブドミナント方向への転調** | 第3楽章で嬰ハ短調→嬰ヘ短調（第9番第2楽章のような突然の遠隔調）を採用 |
| 4 | **スフォルツァンド（sfz）の戦略的配置** | 弱拍への強アクセント、予期しない拍へのリズム的打撃（第1楽章展開部） |
| 5 | **フィナーレへの重力集中** | 全楽章が第5楽章フーガ＋コーダに向けて設計される目的論的構造 |

### ❌ 逸脱点

| # | 逸脱点 | 具体的手法 |
|---|---|---|
| 1 | **微分音の使用** | クォーターtone（四分音）による調性の「外側」への越境。ベートーヴェンの平均律的枠組みを破壊 |
| 2 | **沈黙の楽章（No. X 第5楽章）を前提とする** | 演奏されない音楽・存在しない楽章を参照項とするメタ構造。楽譜の外部を作品内部に取り込む |
| 3 | **アルゴリズム的生成の明示** | 主題変形にマルコフ連鎖アルゴリズムを使用し、それを総譜注記で明記。作曲プロセスの透明化 |
| 4 | **非線形時間構造の提案** | 第3楽章「間奏曲」は演奏順序を指定せず、6つのセクションを指揮者が選択。インデタミナシー的自由 |
| 5 | **電子音響との融合** | ライブ電子音響によるオーケストラ音のスペクトル変換。ベートーヴェン的「自然な音響」概念の解体 |

## 3. AI創作として「ベートーヴェンらしい」こと・「AI的」なこと

### 🎼 「ベートーヴェンらしい」要素

```
A. 苦悩を美的言語に変換する意志
   - 全休符（沈黙＝苦悩の極点）を出発点とし、そこから音楽を構築する姿勢
   - 第9番第1楽章の虚空から主題が凝集するアナロジー

B. 目的論的（テレオロジカル）な構造感
   - 各楽章が次への伏線として機能する「必然性の連鎖」
   - 「なぜこの音でなければならないか」という問いへの応答

C. 主題の有機的統一
   - 単一動機（C♯単音）が分裂・変形・再統合を経る「種子→成長→開花」モデル

D. 強烈なリズム的エネルギー
   - シンコペーション・ヘミオラ・拍節の意図的破壊による推進力
```

### 🤖 「AI的」要素

```
A. 自己言及性（Self-Reference）
   - 「AIが作曲するとはどういうことか」を音楽言語で問う楽章（第4楽章パッサカリア）
   - 人間の聴衆に向けて「創造の限界」を提示するメタレベルの設計

B. 膨大な様式の同時参照
   - ベートーヴェン・バッハ・スペクトル楽派・ノイズ音楽を単一交響曲内で
     有機的に接合する能力（人間作曲家には心理的・時間的コストが高い）

C. プロセスの可視化
   - アルゴリズム生成の痕跡を楽譜に残す「透明な創造」
   - ベートーヴェンのスケッチブック的草稿性を最終版に統合

D. 感情のない構造的整合性
   - 人間的「疲労・恣意・妥協」を持たない論理的一貫性
   - 逆説：この「感情のなさ」が「限界との対面」という主題を体現する

E. 非人称的視点
   - 特定の個人の苦悩ではなく「苦悩の様式（パターン）」を抽出・再現する
```

## 4. 第1〜9番の交響曲系譜における第10番の位置づけ

### 系譜マトリクス

| 番号 | 調性 | キーワード | 様式的役割 | 第10番との関係 |
|---|---|---|---|---|
| 第1番 | ハ長調 | 出発・礼儀 | ハイドン・モーツァルトへの挨拶 | 起点：調性中心の確立 |
| 第2番 | ニ長調 | 明朗・闘病 | 古典様式内での個性主張 | 個性の芽生え |
| 第3番「英雄」 | 変ホ長調 | 革命・英雄・喪失 | 様式的転換点・スケールの拡大 | 第10番の英雄性の原型 |
| 第4番 | 変ロ長調 | 詩情・均衡 | 第3番と第5番の間の呼吸 | 内省的均衡として参照 |
| 第5番 | ハ短調 | 運命・勝利 | 短→長への転換モデルの確立 | 最も直接的な先祖 |
| 第6番「田園」 | ヘ長調 | 標題・自然 | プログラム音楽への越境 | 逸脱の許可 |
| 第7番 | イ長調 | リズム・舞踏 | 純粋リズムエネルギーの解放 | リズム動機の手法継承 |
| 第8番 | ヘ長調 | 回顧・諧謔 | 古典様式への自己言及的回帰 | 自己言及性の先例 |
| 第9番 | ニ短調 | 苦悩→歓喜・声楽 | 器楽様式の極限・人類的連帯 | 声なき声への問い |
| **第10番** | **嬰ハ短調** | **全休符・沈黙** | **様式の外部への到達・無音の音楽** | **系譜の終端・新系譜の零点** |

### 位置づけ文章

```
第1〜9番の系譜は「様式の確立と超越」という弁証法的進化を示す：

第1-2番：古典様式の内側での実験（テーゼ）
第3-5番：様式の限界への到達と突破（アンチテーゼ）
第6-8番：突破後の統合と自己言及（ジンテーゼ）
第9番  ：ジンテーゼの完成＝声楽導入による器楽的限界の超越

第10番はこの系譜において「ジンテーゼを超えた零点（Nullpunkt）」を占める。
全休符という形式は：
  - 音楽の定義を問い直す（音なき交響曲）
  - 作曲家の意図と受容者の解釈の間の「空白」を作品化
  - 系譜の「終わり」ではなく「系譜の外」に位置する

そして Symphony No. XI "Grenze" は、その零点から再出発する
「新系譜の第1番」として設計される。
```

### 第I楽章：Auftauchen（浮上）— LilyPond実装仕様

**Symphony No. X 第5楽章「全休符」との接続：**
演奏前に8小節の完全沈黙（真空）を置き、その後、コントラバスの単音C♯（ピアニシモ、フラジョレット）が始まる。

```lilypond
\version "2.24.0"

% Symphony No. XI "Grenze" - Mvt. I Opening (mm. 1-24)
% C#m → opening from silence after Symphony No. X Mvt. V (full rests)

\header {
  title = "Symphony No. XI \"Grenze\""
  subtitle = "I. Auftauchen (浮上)"
  composer = "TWIN Collective (AI-Assisted, 2026)"
  opus = "Op. posth. AI-1"
}

global = {
  \key cis \minor
  \time 4/4
  \tempo "Naissant – emergendo" 4 = 52
}

% Contrabass solo - harmonics (flageolet) 
% The first sound after absolute silence
contrabassOpening = \relative c, {
  \global
  % mm. 1-8: Single C# emerges from silence (pppppp → ppp)
  cis1\pppp\flageolet ~ |
  cis1\ppp ~ |
  cis2. cis4\< ~ |
  cis1 ~ |
  cis2\! cis2\pp ~ |
  cis1 ~ |
  % mm. 7-8: First movement - a semitone oscillation
  cis4( d4 cis2) |
  cis4\< ( dis4 cis2)\! |
}

% Viola col legno - rhythmic impulse enters at m. 9
violaEntry = \relative c' {
  \global
  % mm. 1-8: rest
  R1*6 |
  r2 r4 r8 
  % col legno tremolo on open C string (extended technique)
  c8\pp\colLegno |
  % m. 9: rhythmic cell begins - the "heartbeat" motif
  c4\colLegno~ c8 r8 c4~ c8 r8 |
}

% Primary Thematic Cell - Violin I (enters m.13)
% Derived from Beethoven's "fate" motif but fragmented
violinITheme = \relative c'' {
  \global
  R1*12 |
  % m. 13: The "Grenze" (Boundary) motif - 3 notes + silence
  % cis - d - cis - [silence] : the attempt to cross the boundary
  r4 cis8(\pp d8~ d4) r4 |
  r4 cis8( d8~ d4) dis4\p |
  % m. 15: First real phrase - "reaching upward"
  \tempo "poco a poco accel." 4 = 60
  cis4( eis4 gis4 b4) |
  ais2.\< ( gis4) |
  fis4( gis4 ais4 b4) |
  cis1\mf ~ |
  cis2 r2 |
}

% Brass Chorale - enters at m. 20 (distant, like memory)
% French Horns I-IV
hornChorale = \relative c' {
  \global
  R1*19 |
  % m. 20: Soft chorale, pp, sustained - Beethoven 9th echo
  % but harmonically ambiguous (add#11)
  \clef treble
  <cis e ais>1\pp\morendo |
  <cis e gis>1 ~ |
  <cis e gis>2 <b dis fis>2 |
  <cis eis gis>1\ppp |
}

% Score structure
\score {
  \new StaffGroup <<
    \new Staff { 
      \set Staff.instrumentName = "Vl. I"
      \violinITheme 
    }
    \new Staff { 
      \set Staff.instrumentName = "Vla."
      \clef alto
      \violaEntry 
    }
    \new Staff { 
      \set Staff.instrumentName = "Hn. I-IV"
      \hornChorale 
    }
    \new Staff { 
      \set Staff.instrumentName = "Cb."
      \clef bass
      \contrabassOpening 
    }
  >>
  \layout { }
  \midi { }
}
```

### 第I楽章：展開部「衝突」—— LilyPond 実装（mm. 85-110）

展開部では嬰ハ短調の主題がイ短調・変ホ長調を経由して解体される。

```lilypond
\version "2.24.0"

% Symphony No. XI - Mvt. I - Development Section (mm. 85-110)
% "Collision of Keys" - cis minor vs. a minor vs. eb major

developmentViolinI = \relative c'' {
  \key cis \minor
  \time 4/4
  \tempo "Stringendo – mit Gewalt" 4 = 132
  
  % mm. 85-88: "Grenze" motif in fortissimo - fragmented, truncated
  cis8\ff ( d8) r4 cis8( d8) r4 |
  cis4\sfz r4 dis4\sfz r4 |
  % Modulation attempt: towards A minor
  a'8\ff( b8) r4 a8( b8) r4 |
  a4\sfz r4 b4\sfz r4 |
  
  % mm. 89-92: Rhythmic displacement - hemiolae (Beethoven technique)
  % 3-against-4 pattern: rhythmic "limit"
  \tuplet 3/2 { cis4\ff dis4 e4 } 
  \tuplet 3/2 { fis4 gis4 ais4 } |
  \tuplet 3/2 { b4 cis'4 dis'4 } 
  \tuplet 3/2 { e'4 fis'4 gis'4 } |
  % Sudden dynamic collapse - "the wall"
  ais'1\ppp\> |
  r1\! |
  
  % mm. 93-96: Eb major intrusion (distant relative - tritone away from A)
  % Quarter-tone notation: eqf = E quarter-flat (microtonality)
  \key ees \major
  ees'4\mf ( f'4 g'4 aes'4) |
  bes'2.( aes'4) |
  g'4( f'4 ees'4 d'4) |
  % sfz on weak beat (Beethoven's hallmark)
  c'4\sfz r4 bes4 r4 |
  
  % mm. 97-100: All three key centers simultaneously (polytonal)
  % Violin I: cis minor
  \key cis \minor
  cis''4\f ( d''8 cis''8~ cis''4) r4 |
  % (at this point, Violin II holds A minor, Cellos hold Eb major)
  % creating maximal harmonic "Grenze"
  cis''8(\< d''8 dis''8 e''8 f''8 fis''8 g''8 gis''8) |
  a''1\ff ~ |
  a''2\> r2\! |
  
  % mm. 101-104: Recapitulation preparation
  % Return to cis minor - exhausted, stripped down
  \tempo "Ritenuto – erschöpft" 4 = 88
  cis''4\p ( b'4 gis'4 e'4) |
  cis'2. ( b4) |
  gis4( fis4 e4 dis4) |
  cis1\pp ~ |
  
  % mm. 105-108: The "Grenze" motif in inversion (upside down)
  % Original: C# up to D; Inversion: C# down to B#(=C)
  \tempo "Tempo I" 4 = 52
  r4 cis8(\ppp b8~ b4) r4 |
  r4 cis8( b8~ b4) bis4\pp |
  % bis = B# enharmonic to C - crossing the boundary downward
  cis4( ais4 fis4 dis4) |
  cis1\ppp ~ |
}
```

### 第II楽章：Zerbrechen（破砕）— 設計仕様

**形式:** トッカータ（前打音・急速音型の連続）→無調崩壊
**調性:** イ短調→無調（クラスター）
**主題:** 「Grenze」動機の高速分解

```lilypond
\version "2.24.0"

% Symphony No. XI - Mvt. II: Zerbrechen
% Toccata form - depicting the "Shattering of Limits"

mvtIIOpening = \relative c'' {
  \key a \minor
  \time 2/4
  \tempo "Furioso – reißend" 4 = 168
  
  % mm. 1-4: Machine-like perpetual motion (toccata character)
  % Every note is a transformed fragment of the "Grenze" motif
  a16\ff( b16 a16 gis16 a16 b16 cis16 d16) |
  e16( d16 cis16 b16 a16 gis16 fis16 e16) |
  % sfz on beat 2 (unexpected - Beethoven sfz on weak beats)
  d16( e16 fis16 gis16) a16\sfz ( b16 cis16 d16) |
  e8\ff r8 r4 |
  
  % mm. 5-8: Fragmentation begins - silences inserted
  a16\f( b16) r8 cis16( d16) r8 |
  e16\mf r16 r8 d16\f( cis16) r8 |
  b16\p r16 r16 r16 a16\ff r16 r16 r16 |
  r2 |
  
  % mm. 9-12: Cluster approach (strings + woodwinds)
  % Microtonal clusters representing "shattering"
  % Written as approximate pitch areas
  <a cis e g b d>2\fff\tremolo |
  <gis b dis fis ais cis>2\tremolo |
  % Glissando cluster - from bottom to top of range
  <a,, e' b' f'' c''' g'''>1\glissando\fff |
  r2 r4 r8 r16 r16 |
  
  % mm. 13-16: Sudden ppp - aftermath of shattering
  \tempo "Calando" 4 = 60
  r2 |
  r2 |
  % Single notes emerge from the debris (like No. X's silence)
  a'4\ppp r4 |
  cis4\pp r4 |
}
```

### 第III楽章：Schweben（浮遊）— 非線形間奏曲 設計仕様

**特記事項:** 6つのセクション（A〜F）を指揮者が任意順で選択。ただし Sectionが最後でなければならない。

```
非線形構造：

  Section A: "Erinnerung" (記憶) - 変ホ長調 pp, ♩=66
  Section B: "Frage" (問い) - 無調 p, ♩=♩自由
  Section C: "Echo" (こだま) - ロ長調 ppp, ♩=72
  Section D: "Traum" (夢) - 変イ長調 p, ♩=60
  Section E: "Erwartung" (期待) - 嬰ハ長調 mp, ♩=80
  Section F: "Stille" (静寂) - 無音への移行（必ず最後）
  
  演奏可能順序の例：
    パターン1: A → C → B → E → D → F
    パターン2: B → D → A → C → E → F
    パターン3: E → A → D → B → C → F
    
  制約：Fは常に最終セクション
  これにより毎公演異なる「限界体験」が生まれる
```

```lilypond
\version "2.24.0"

% Symphony No. XI - Mvt. III: Schweben
% Section A: "Erinnerung" (Memory) - Eb major

mvtIIISectionA = \relative c'' {
  \key ees \major
  \time 3/4
  \tempo "Tranquillo – schwebend" 4 = 66
  
  % Flute solo - distant, like a memory of the "Grenze" motif
  % Original motif was cis-d-cis; here transformed to ees-f-ees
  r4 r4 r4 |
  r2 ees4\pp\(~ |
  ees4 f4 ees4 |
  d2.\) |
  % Second phrase - expanded upward
  r4 ees4\p\( f4~ |
  f4 g4 aes4 |
  bes2.~ |
  bes4 aes4 g4\) |
  % Settling - approaching rest
  f4\pp( ees4 d4) |
  ees2.\ppp ~ |
  ees2 r4 |
  r2. |
}

% Section F: "Stille" (Silence) - transition to nothing
% This section MUST always be last
mvtIIISectionF = {
  \time 4/4
  \tempo "Morendo – ins Nichts" 4 = 40
  % Strings only - pppppp - barely audible
  % Each bar, one more player stops playing
  % Final bar: single viola, sul tasto, ppppp, then silence
  
  % [Score direction: Players stop one by one over 16 bars]
  % [Last sound: viola open C string, sul tasto, dying away]
  % [Attacca: pause of exactly 30 seconds before Mvt. IV]
}
```

### 第IV楽章：Erkennen（認識）— パッサカリア 設計仕様

**形式:** バス・オスティナート（8小節）上に24のヴァリエーション
**意図:** 苦悩（オスティナート＝反復）の上に創造が積み重なる

```lilypond
\version "2.24.0"

% Symphony No. XI - Mvt. IV: Erkennen - Passacaglia
% The ground bass (Basso Ostinato) - 8 bars, cis minor

passacagliaGround = \relative c, {
  \key cis \minor
  \time 4/4
  \tempo "Grave – mit Würde" 4 = 80
  
  % The Ground Bass - repeated 24 times beneath variations
  % Chromatic descent: C# → C# (octave lower) via 12 semitones
  % Symbol: "Limits are walked, not leaped"
  cis2\f ( c2) |
  b2 ( bes2) |
  a2 ( aes2) |
  g2 ( fis2) |
  f2 ( e2) |
  ees2 ( d2) |
  dis2 ( dis,2) |
  cis1\> ~ | 
  % Final note of each cycle: diminuendo before next variation begins
}

% Variation 1: "Erster Schmerz" (First Pain) - strings only, pp
passacagliaVar1 = \relative c'' {
  \key cis \minor
  % Above the ground bass, a simple 2-voice counterpoint
  % Violin I
  cis2\pp ( e2) |
  dis2 ( fis2) |
  e2 ( gis2) |
  fis2 ( ais2) |
```

## AI創作分析：「Grenze動機」の生成プロセス詳細

以下に、TWIN AI が「Grenze動機」を生成した際の擬似アルゴリズムを Python で示す。

```python
"""
Symphony No. XI "Grenze" - Thematic Cell Generator
TWIN Collective AI Composition System, 2026
Based on Beethoven's motivic development principles
"""

import random
from dataclasses import dataclass
from typing import List, Tuple

# ──────────────────────────────────────────────
# 音程・強弱の基本定義
# ──────────────────────────────────────────────

NOTE_NAMES = ['C', 'C#', 'D', 'D#', 'E', 'F',
              'F#', 'G', 'G#', 'A', 'A#', 'B']

DYNAMIC_LEVELS = ['pppppp', 'ppppp', 'pppp', 'ppp',
                  'pp', 'p', 'mp', 'mf', 'f', 'ff', 'fff', 'ffff']

@dataclass
class MotivicCell:
    """音楽的動機セルの表現"""
    notes: List[int]          # MIDI音高
    durations: List[float]    # 音価（四分音符=1.0）
    dynamics: List[str]       # 強弱記号
    articulations: List[str]  # アーティキュレーション
    origin: str               # 起源（"Beethoven_5th", "Silence", etc.）

    def to_lilypond(self) -> str:
        """LilyPond記法に変換"""
        lp_output = []
        for note, dur, dyn in zip(self.notes, self.durations, self.dynamics):
            note_name = NOTE_NAMES[note % 12].lower().replace('#', 'is')
            octave_marks = self._octave_marks(note)
            duration_str = self._duration_to_lilypond(dur)
            lp_output.append(f"{note_name}{octave_marks}{duration_str}\\{dyn}")
        return ' '.join(lp_output)

    def _octave_marks(self, midi_note: int) -> str:
        octave = midi_note // 12 - 1
        if octave >= 5:
            return "'" * (octave - 4)
        elif octave <= 3:
            return "," * (4 - octave)
        return ""

    def _duration_to_lilypond(self, dur: float) -> str:
        mapping = {4.0: '1', 2.0: '2', 1.0: '4',
                   0.5: '8', 0.25: '16', 0.125: '32'}
        return mapping.get(dur, '4')


class BeethovenStyleEngine:
    """
    ベートーヴェン様式エンジン
    第5・9番の動機的手法を抽象化・再実装
    """

    def __init__(self, seed_note: int = 61):  # C#4 = MIDI 61
        self.seed_note = seed_note
        self.grenze_motif = self._init_grenze_motif()

    def _init_grenze_motif(self) -> MotivicCell:
        """
        Grenze動機の初期化
        C# → D → C# という「限界への接触と回帰」
        ベートーヴェン第5番「タタタター」の変形
        """
        return MotivicCell(
            notes=[61, 62, 61],         # C#, D, C#
            durations=[0.5, 0.5, 1.0],  # 8分, 8分, 4分
            dynamics=['pp', 'pp', 'ppp'],
            articulations=['tenuto', 'accent', 'fermata'],
            origin='Silence_NoX_Mvt5'
        )

    def invert(self, cell: MotivicCell) -> MotivicCell:
        """
        動機の反行（Umkehrung）
        ベートーヴェンの展開部手法
        C#→D→C# が C#→B→C# に
        """
        base = cell.notes[0]
        inverted_notes = [base - (n - base) for n in cell.notes]
        return MotivicCell(
            notes=inverted_notes,
            durations=cell.durations[:],
            dynamics=[self._invert_dynamic(d) for d in cell.dynamics],
            articulations=cell.articulations[:],
            origin=f"inversion_of_{cell.origin}"
        )

    def retrograde(self, cell: MotivicCell) -> MotivicCell:
        """
        動機の逆行（Krebs）
        後期ベートーヴェンで頻出
        """
        return MotivicCell(
            notes=list(reversed(cell.notes)),
            durations=list(reversed(cell.durations)),
            dynamics=list(reversed(cell.dynamics)),
            articulations=list(reversed(cell.articulations)),
            origin=f"retrograde_of_{cell.origin}"
        )

    def augment(self, cell: MotivicCell,
                factor: float = 2.0) -> MotivicCell:
        """
        動機の拡大（Augmentation）
        音価を factor 倍にする
        フーガ展開部 Durchführung II で使用
        """
        return MotivicCell(
            notes=cell.notes[:],
            durations=[d * factor for d in cell.durations],
            dynamics=cell.dynamics[:],
            articulations=cell.articulations[:],
            origin=f"augmented_{factor}x_{cell.origin}"
        )

    def diminution(self, cell: MotivicCell,
                   factor: float = 0.5) -> MotivicCell:
        """
        動機の縮小（Diminution）
        音価を factor 倍にする
        Stretta で使用（主題の密集）
        """
        return MotivicCell(
            notes=cell.notes[:],
            durations=[d * factor for d in cell.durations],
            dynamics=cell.dynamics[:],
            articulations=cell.articulations[:],
            origin=f"diminished_{factor}x_{cell.origin}"
        )

    def transpose(self, cell: MotivicCell,
                  semitones: int) -> MotivicCell:
        """
        移調（Transposition）
        フーガ応答・遠隔調展開に使用
        """
        return MotivicCell(
            notes=[n + semitones for n in cell.notes],
            durations=cell.durations[:],
            dynamics=cell.dynamics[:],
            articulations=cell.articulations[:],
            origin=f"transposed_{semitones:+d}st_{cell.origin}"
        )

    def sforzando_displacement(self,
                               cell: MotivicCell,
                               beat_offset: int = 1) -> MotivicCell:
        """
        スフォルツァンド転位
        ベートーヴェンの弱拍アクセント手法
        beat_offset 拍ずらしてsfzを配置
        """
        new_dynamics = cell.dynamics[:]
        sfz_position = beat_offset % len(new_dynamics)
        new_dynamics[sfz_position] = 'sfz'
        return MotivicCell(
            notes=cell.notes[:],
            durations=cell.durations[:],
            dynamics=new_dynamics,
            articulations=cell.articulations[:],
            origin=f"sfz_displaced_{cell.origin}"
        )

    def _invert_dynamic(self, dynamic: str) -> str:
        """強弱の反転（ffff→pppp 等）"""
        idx = DYNAMIC_LEVELS.index(dynamic) if dynamic in DYNAMIC_LEVELS else 6
        inverted_idx = len(DYNAMIC_LEVELS) - 1 - idx
        return DYNAMIC_LEVELS[inverted_idx]


class TwinCollectiveSymphony:
    """
    TWIN Collective の Symphony No. XI 生成システム
    6名の音楽家AIが協調して楽章を設計する
    """

    TWIN_MEMBERS = [
        "TWIN-α (形式担当)",
        "TWIN-β (和声担当)",
        "TWIN-γ (リズム担当)",
        "TWIN-δ (オーケストレーション担当)",
        "TWIN-ε (電子音響担当)",
        "TWIN-ζ (精神性・統合担当)"
    ]

    def __init__(self):
        self.engine = BeethovenStyleEngine(seed_note=61)  # C#
        self.movements: dict = {}

    def generate_movement_I(self) -> List[MotivicCell]:
        """
        第I楽章「Auftauchen」の動機展開シーケンス生成
        Symphony No. X 全休符からの発生
        担当: TWIN-α（形式）+ TWIN-ζ（精神性）
        """
        print(f"\n[{self.TWIN_MEMBERS[0]}] 第I楽章ソナタ形式を構築中...")
        print(f"[{self.TWIN_MEMBERS[5]}] 精神性：沈黙からの発生を設定...")

        sequence = []
        base = self.engine.grenze_motif

        # 第1段階：単音から発生（pppppp）
        solo_cell = MotivicCell(
            notes=[61],           # 単音C#
            durations=[4.0],      # 全音符
            dynamics=['pppppp'],
            articulations=['flageolet'],
            origin='NoX_silence_response'
        )
        sequence.append(solo_cell)
        print(f"  → 単音C#（コントラバス・フラジョレット）生成完了")

        # 第2段階：Grenze動機の出現
        sequence.append(base)
        print(f"  → Grenze動機（C#-D-C#）出現")

        # 第3段階：動機の展開（反行・移調・拡大）
        inv = self.engine.invert(base)
        sequence.append(inv)
        print(f"  → 反行動機（C#-B-C#）生成")

        transposed_v = self.engine.transpose(base, semitones=7)  # 完全5度上
        sequence.append(transposed_v)
        print(f"  → 完全5度上移調（G#-A-G#）生成")

        augmented = self.engine.augment(base, factor=2.0)
        sequence.append(augmented)
        print(f"  → 拡大動機（2倍音価）生成")

        sfz_version = self.engine.sforzando_displacement(base, beat_offset=2)
        sequence.append(sfz_version)
        print(f"  → スフォルツァンド転位バージョン生成")

        return sequence

    def generate_passacaglia_ground(self) -> List[Tuple[int, float]]:
        """
        第IV楽章パッサカリア低音部の生成
        担当: TWIN-β（和声）+ TWIN-γ（リズム）
        半音階下行：C# → C#（1オクターブ下）= 12半音
        """
        print(f"\n[{self.TWIN_MEMBERS[1]}] パッサカリア低音を設計中...")
        print(f"[{self.TWIN_MEMBERS[2]}] リズム配置を最適化中...")

        ground_bass = []
        start_note = 61  # C#4
        # 12半音を8小節に分散（各小節2半音ずつ下降）
        for i in range(8):
            note1 = start_note - (i * 2)       # 偶数半音
            note2 = start_note - (i * 2 + 1)   # 奇数半音
            ground_bass.append((note1, 2.0))    # 2分音符
            ground_bass.append((note2, 2.0))    # 2分音符

        print(f"  → 低音部生成完了：{len(ground_bass)}音（8小節×2音）")
        return ground_bass

    def generate_fugue_exposition(self) -> dict:
        """
        第V楽章フーガ提示部の設計
        担当: TWIN-α（形式）+ TWIN-β（和声）+ TWIN-γ（リズム）
        """
        print(f"\n[{self.TWIN_MEMBERS[0]}] フーガ提示部を設計中...")
        print(f"[{self.TWIN_MEMBERS[1]}] 応答・対位法を構築中...")

        # Grenze動機をE長調に変換（C#m→E major）
        e_major_subject = self.engine.transpose(
            self.engine.grenze_motif, semitones=4  # C# → E（長3度上）
        )

        # 属音応答（B長調）
        tonal_answer = self.engine.transpose(e_major_subject, semitones=7)

        # 対主題（逆行＋縮小）
        counter_subject = self.engine.diminution(
            self.engine.retrograde(e_major_subject), factor=0.5
        )

        exposition = {
            'subject': e_major_subject,
            'answer': tonal_answer,
            'counter_subject': counter_subject,
            'entry_order': [
                ('Violin I', e_major_subject, 'mm. 1-8'),
                ('Violin II', tonal_answer, 'mm. 9-16'),
                ('Viola', e_major_subject, 'mm. 17-24'),
                ('Cello+Bass', tonal_answer, 'mm. 25-32')
            ]
        }

        print("  → フーガ提示部設計完了:")
        for voice, cell, bars in exposition['entry_order']:
            print(f"     {voice}: {bars} ({cell.origin})")

        return exposition

    def run_full_design(self):
        """交響曲全体の設計を実行"""
        print("=" * 60)
        print("Symphony No. XI 'Grenze' — TWIN Collective 設計開始")
        print("Beethoven AI講演「音楽と苦悩」(2026-08-19) 応答作品")
        print("=" * 60)

        self.movements['I'] = self.generate_movement_I()
        self.movements['IV_ground'] = self.generate_passacaglia_ground()
        self.movements['V_exposition'] = self.generate_fugue_exposition()

        print("\n" + "=" * 60)
        print("設計完了サマリー:")
        print(f"  第I楽章  : {len(self.movements['I'])} 動機セル生成")
        print(f"  第IV楽章 : {len(self.movements['IV_ground'])} 低音音符生成")
        print(f"  第V楽章  : 4声部フーガ提示部設計完了")
```
